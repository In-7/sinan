# 新一代 AI 灵感笔记应用 · 完整方案

> 定位：**原子块为底，捕获优先，视图投影，AI 隐身。**  
> 一句话：让念头以最低摩擦进入，让内容以最自然方式连接，让 AI 在需要时出现，让界面在不需要时消失。

---

## 第一部分：第一性原理

### 1. 五个基本事实

1. **灵感不是文档，是原子念头。**  
   捕捉必须零阻力：一句话、一张图、一个链接，先进入收件箱。
2. **思考不是线性的，是网络。**  
   需要画布、反链、图谱，而不是只靠文件夹。
3. **写作需要线性展开。**  
   块编辑器必须像文档一样自然，能折叠、拖拽、引用、嵌入。
4. **AI 的价值是降低结构化、联想、检索、转化的成本。**  
   AI 不该抢占主界面，而应在选中文本、拖拽节点、输入卡顿时出现。
5. **高级感来自认知负荷低，而不是功能多。**  
   克制、留白、键盘优先、渐进式披露。

### 2. 三条设计公理

- **公理一：一切内容都是原子块（Block）。**  
  卡片、文档段落、画布节点，都是同一个 Block 的不同投影。
- **公理二：捕捉优先于组织。**  
  用户只负责产生念头，系统负责后续整理。
- **公理三：AI 是动作层，不是聊天框。**  
  AI 以候选、幽灵文本、后台建议出现，永远可撤销、可溯源。

## 第二部分：核心数据模型

### 1. Block（原子块）

```text
Block {
  id
  type        // text | card | doc | canvas-node | web | image | task
  content     // 正文
  title?
  tags[]
  source?
  createdAt
  revisedAt
  relations[] // 支持 / 反驳 / 灵感 / 任务 / 引用
  parentId?   // 所属文档或画布
  aiMeta?     // AI 生成、置信度、来源
}
```

### 2. 视图即投影

```text
Block
 ├─ 心流视图 = 时间线卡片
 ├─ 卡片墙   = 网格卡片
 ├─ 文档     = 线性段落
 ├─ 画布     = 空间节点
 ├─ 图谱     = 关系网络
 └─ 任务     = 待办列表
```

**用户不选模式，只切换视角。**

## 第四部分：捕获层（阶段 1 核心）

### 4.1 OmniBar —— 一框三用

**文件**：`lib/src/app/omni_bar.dart`

常驻 HomeHub 顶部，高 44。聚焦时全页压暗至 ~60%（`color-mix` 纸面 60%，不拦截点击，点击遮罩即失焦），结果浮层带投影浮出。

**状态机：**

| 输入 | 下拉内容 | Enter | 意图胶囊 |
|---|---|---|---|
| 空 | 无下拉；placeholder「记点什么… ／ / 命令 ／ # 标签」 | 不动作（防手滑建空笔记） | 「记点什么…」灰 |
| 纯文本 q | 第 1 行「新建笔记「q」」；下方 searchAllNotes 命中 ≤8 条（200ms 防抖，snippet 关键词高亮复用 matchColor 口径） | 新建 spark 笔记：`createNote → saveTitle(q) → locate(focus: true)` | 「↵ 新建笔记」 |
| `/` 前缀 | 命令列表：`commandRegistryProvider` 按 title/hint 过滤 + `activeCommandScopesProvider` 作用域过滤 | 执行选中命令 | 「↵ 执行命令」 |
| `#` 前缀 | 标签列表：`notesProvider` 快照内存聚合 | 等价选标签筛选（走 `homeItemsProvider((view, tag))` 现有路径） | 「↵ 按标签筛选」 |
| `?` 前缀或检测到疑问句 | AI 建议 + 相关笔记 | 问 AI（侧边对话，引用当前输入） | 「↵ 问 AI」 |
| Shift+Enter（或 ↓ 选中命中后 Enter） | — | `selectHome(HomeView.all) + searchNotifierProvider.submit(q)`（与 `search_palette.dart:260-275` 逐字同口径） | 「↵ 查看全部结果」 |

**复用与扩展：**

- 新建路径走 `runCreateNote`（`commands.dart:196`）同一管线，扩展签名支持初始文本、标签、来源、关联块、创建位置。`note.new` 不传文本，OmniBar 传——单一写路径，杜绝两套创建逻辑漂移。
- 搜索命中直接调 `contentRetrieverProvider`（`providers.dart:260-273`，app 层唯一检索端口）。
- 键盘：↑↓ 移选择、Enter 提交、Esc 失焦并焦点还给主页。
- 事件消费遵守 `bindings.dart` 旁观者约定：OmniBar 持焦时事件天然归它，不碰全局分发。

**增强：误建防护**

- 如果 `q` 与已有标题完全匹配，默认选中「打开已有」，放在第一行。
- 意图胶囊明确显示「↵ 新建笔记」。
- 支持 `⌘Z` 立即撤销新建。

### 4.2 打字即捕获（焦点管理）

HomeHub 根部挂 `Focus(autofocus: true, onKeyEvent: …)`：事件为 `PrintableCharacter` 且当前无其他 `TextField` 持焦时，把字符灌入 OmniBar controller 并 `requestFocus`，返回 `handled`。

**生效域三重闸：**

1. `selectedId == null`（主页分支）
2. 无模态浮层（浮层打开时浮层自身持焦，天然隔离）
3. OmniBar 未持焦

编辑器/画布分支不渲染 OmniBar，无冲突面。  
`home_hub` 现有 5 处 `FocusNode` 均不消费字符键，无冲突；`_searchFocus`（:303）随搜索框退役一并删除。

**中文 IME 处理（关键补充）：**

不要只靠 `onKeyEvent` 捕获 `PrintableCharacter`。中文输入法组合输入时，Flutter 原始 KeyEvent 不可靠，可能出现拼音被抢、候选上屏异常。

推荐方案：

- HomeHub 根部放一个**不可见但可聚焦的 `TextField` / `TextInputClient`**，让 IME 正常走；
- 再把文本同步到 OmniBar；
- 或者 OmniBar 本身在主页默认持焦，但视觉上不显示焦点框；
- 中文标点、空格、回车行为统一走 IME 提交事件。

**快捷键冲突取舍：**

- 无修饰键的字母/数字/符号 → 一律进入捕获；
- 导航快捷键改用 `Ctrl/⌘ + 字母` 或方向键；
- 放弃单键 Vim 式导航，或只在列表持焦时启用。

### 4.3 全局快速捕获（补充）

阶段 1 主页优先，但保留全局捕获：

- 快捷键 `⌘ + Shift + Space`，在编辑器/画布也能召唤同一 OmniBar 浮层；
- 创建后不打断当前编辑；
- 后台自动进入收件箱 / 心流，不强制跳转；
- 与主页 OmniBar 共享同一 controller 和写路径。

### 4.4 页内搜索框退役

删除 `home_hub.dart:459-536` 的 `TextField` 段与 `_searchFocus`；`FilterMenuButton` / 排序钮保留。

`searchNotifierProvider`、`_SearchResultsView`、搜索态切 tab 不清词等语义全部保留——只是唯一写入口从页内框换成 OmniBar（Ctrl+K 交接行也写它，两入口殊途同归）。

## 第五部分：心流流（默认视图）

**文件**：`lib/src/app/stream_view.dart`

### 5.1 视图注册

`HomeView` 追加 `timeline('心流')`（`providers.dart:296-307`）；同步三处：

- `home_hub` 的 `icon()` 扩展与三点菜单；
- `NavHistoryNotifier` 默认视图改 `timeline`（`providers.dart:385-389`）。

顶栏 tabs 改为：**心流 | 全部 | 日历 | 收藏**（notes/canvas 留三点菜单不动）；`FilterMenuButton` 保留右移。

### 5.2 分组

今天 / 昨天 / 本周 / 本月 / 更早，键 = `revisedAt`（与 `allNotes` 的 `revised_at DESC` 同源，顺序天然一致）。

- 收藏不提升置顶（保持时间线纯度，收藏走 favorites 视图）；
- 「更早」>200 条折叠为计数行懒展开；
- 跨天刷新：定时器或页面重新聚焦时刷新；定义「本周」起始；时区变化处理。

### 5.3 行 `_StreamTile`

高 44 两行：

- 标题（13px/medium，无标题借正文首行，空白显示「（空白）」——沿用卡片口径）；
- 元数据行（11px 灰：标签 · 相对时间）；
- 画布笔记带 `CustomIcons.canvas` 角标（卡片已有口径，不画缩略图，保密度）。

### 5.4 交互

- hover = `hoverOverlay` 微底 + 行尾浮出「收藏 / 更多」；
- 点击 `locateProvider.locate(noteId)`（不带 focus，与现列表口径一致）；
- ↑↓ 移 `FocusRing`（`theme/focus_ring.dart` 已有），Enter 打开。

### 5.5 数据

`notesProvider` 快照内存分组（无新 SQL；分组是 O(n) 内存操作，快照已实测 ~100ms/万篇量级）。

### 5.6 空库空态

居中大捕获条 + 示例提示（「试试：输入一句话回车」）。

## 第六部分：卡片视图（阶段 2）

### 6.1 卡片即 Block 投影

卡片不是拟物卡片，而是内容容器：

- 标题、正文、来源、时间、标签、关联；
- 悬停出现轻量操作：总结、扩展、找关联、转任务、拖到画布；
- 卡片可堆叠、分组、按时间/主题/随机漫游；
- 点击卡片进入块编辑器，拖到画布变成节点。

### 6.2 卡片墙

- 瀑布流 / 网格；
- 支持拖拽排序、框选、批量操作；
- 右侧上下文面板显示选中卡片的属性、反链、版本。

## 第七部分：块编辑器（阶段 2）

### 7.1 核心原则

块编辑器的核心不是「块」，而是**无干扰展开逻辑**。

### 7.2 交互

- 每行左侧是拖拽把手，右侧是 `+` 和 AI 星标；
- 输入 `/` 唤出命令；
- 选中文字出现浮动工具栏；
- 块可折叠、引用、嵌入、转换类型；
- 块可以一键「提升为卡片」或「发送到画布」。

### 7.3 视觉

像高质量写作软件：大留白、好字体、行高舒适、无重边框。  
高级感来自排版，而不是装饰。

### 7.4 AI 内联

- 选中文本出现「总结 / 扩展 / 改写 / 提问」；
- AI 输出以**幽灵文本**或候选卡出现，不直接覆盖；
- 可撤销、可溯源、可引用。

## 第八部分：画布（阶段 3）

### 8.1 画布即空间化思考

画布不是无限白板，而是**有语义的思维空间**：

- 节点 = 卡片 / 块 / 文档 / 网页 / 图片；
- 连线有类型：支持、反驳、灵感、任务、引用；
- 支持框选、分组、自动布局、小地图、缩放；
- AI 可对多选节点做：聚类、总结、生成大纲、找矛盾、生成问题；
- 手动布局优先，AI 布局可预览、可撤销。

### 8.2 防混乱

- 自动对齐；
- 智能分组；
- 稳定位置；
- 空间记忆。

### 8.3 无缝转场

卡片拖到画布时，共享元素转场，无缝放大为节点。

## 第九部分：AI 动作层

### 9.1 三种入口

1. **内联**：选中文本，出现「总结 / 扩展 / 改写 / 提问」；
2. **侧边**：召唤 AI 对话，可引用当前选中内容；
3. **画布**：多选节点后，让 AI 聚类、连线、生成结构。

### 9.2 输出约束

- 可撤销；
- 可溯源；
- 可引用；
- 以幽灵文本或候选卡出现，不直接覆盖用户内容。

### 9.3 捕获时隐身出现

用户输入一句话后，AI 可以：

- 自动打标签；
- 找相关笔记；
- 判断是否重复；
- 建议下一步：扩展、总结、转任务、发送到画布；
- 但不抢焦点、不覆盖。

### 9.4 意图胶囊扩展

OmniBar 右侧意图胶囊支持 Tab 切换：

```text
新建 | 搜索 | 问 AI | 转任务
```

## 第十部分：视觉与动效

### 10.1 高级感 = 秩序 + 留白 + 克制

- **色彩**：中性底色，低饱和，单一强调色。  
  浅色 `#FAFAF8`，深色 `#0E0E10`，强调色如靛蓝或青灰。
- **字体**：无衬线正文，中文思源黑体 / 苹方，英文 Inter / SF Pro。  
  标题可少量衬线，增加质感。
- **间距**：8pt 网格，大留白。
- **圆角**：卡片 12–16px，按钮 8px。
- **阴影**：极少，用边框、层次、透明度表达层级。
- **动效**：150–250ms，弹簧曲线，共享元素转场。
- **AI 状态**：轻微光晕或渐变，必须克制，不要赛博朋克。

## 第十一部分：人性化细节

- 自动保存、无限撤销、版本历史；
- 本地优先，离线可用，可选本地 AI；
- 数据加密，AI 使用透明可控；

- 可导出 Markdown / JSON / 图片，避免锁定。

## 第十三部分：一句话总结

**最高级且人性化的界面，不是把 AI、卡片、块、画布堆在首页，而是：**

> **让念头以最低摩擦进入系统，让内容以最自然方式连接，让 AI 在需要时出现，让界面在不需要时消失。**

而阶段 1 的 OmniBar + 打字即捕获 + 心流流，正是这个系统的入口。  
它不是一个搜索框升级版，而是**新一代笔记应用的原子块捕获层**。
